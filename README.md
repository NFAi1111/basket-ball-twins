# Hoops Lab 3D — คู่มือใช้งานและนำขึ้นเว็บ

เว็บแอปจำลองแผนบาสเกตบอลแบบ 3 มิติ (ครึ่งสนาม · 5 on 5 / 3 on 3 · ติดตั้งเป็นแอปบนมือถือได้ · ใช้งานออฟไลน์ได้หลังเปิดครั้งแรก)

## ไฟล์ในโฟลเดอร์
| ไฟล์ | หน้าที่ |
|---|---|
| index.html | หน้าเว็บหลัก |
| app.js | ตัวแอปทั้งหมด |
| style.css | หน้าตา |
| config.js | **ไฟล์เดียวที่คุณต้องแก้** ใส่ลิงก์ Google Sheets |
| manifest.json, sw.js, icons/ | ทำให้ติดตั้งเป็นแอปและใช้ออฟไลน์ได้ |
| sheet-template.csv | ตัวอย่างชีตแผนโจมตี นำไปเปิดใน Google Sheets ได้เลย |

## โหมดต่อสู้ ⚔ เทิร์นเบส RPG (แท็บ "⚔ RPG ต่อสู้")
1. ตั้งเป้าแต้ม (เริ่มต้น 21) เลือกเล่นกับ CPU หรือ 2 ผู้เล่น แล้วกด "เริ่มเกม"
2. ฝั่งบุกคือ **สีแดง** ฝั่งรับคือ **สีน้ำเงิน** ป้ายเหนือหัวบอกตำแหน่ง (PG/SG/SF/PF/C) ฝั่งรับเป็น AI ระดับ NBA เลือกแผนเองทุกครั้ง และบอกให้ทราบว่าใช้แผนอะไร (เช่น โซน 2-3)
3. ที่การ์ดสั่งการ: เลือกผู้เล่น → เลือกคำสั่ง → ตัวละครนั้นขยับตามที่เลือก
   - คนถือบอล: ส่งบอล (ไฟเขียว/เหลือง/แดง บอกความเสี่ยงโดนตัด), ไดรฟ์, เลี้ยงไปจุด, ยิง
   - คนไม่มีบอล: ย้ายไปจุด, คัตเข้าแป้น, V-cut, ตั้งสกรีน, โรล/ป๊อป (เมื่ออยู่ใกล้คนถือบอล)
4. มีจำนวนจังหวะจำกัดต่อการครองบอล (5on5 = 4, 3on3 = 3) เมื่อหมดต้องยิง
5. ยิงเข้าได้แต้ม สลับฝั่ง ทีมแรกถึงเป้าแต้มชนะ

## แผนบุกหลาย option
เลือกแผนที่ชื่อลงท้ายว่า "(3 ทางเลือก)" หรือ 3x3 ในรายการแผนบุก แผนจะเล่นช่วงต้นแล้วหยุด แสดงทางเลือก (พร้อมคะแนนคาดหวัง) ให้เลือกต่อ หรือกด "ให้ระบบเลือก"

## 1) ทดลองบนเครื่อง
ดับเบิลคลิก `index.html` (ต้องต่ออินเทอร์เน็ต) ฟีเจอร์ติดตั้งแอปกับดึง Google Sheets จะทำงานเมื่อขึ้นเว็บจริงแล้วเท่านั้น

## 2) นำขึ้นเว็บฟรี (เลือกวิธีเดียว)
**Netlify (ง่ายสุด):** เปิด app.netlify.com/drop แล้วลากทั้งโฟลเดอร์นี้ไปวาง ได้ลิงก์ทันที
**GitHub Pages:** สร้าง repository อัปโหลดทุกไฟล์ → Settings → Pages → เลือก branch main → Save

ต้องเป็นลิงก์ https เท่านั้น (สองวิธีข้างบนให้ https อยู่แล้ว)

## 3) ต่อ Google Sheets เป็นฐานข้อมูล
1. เปิด `sheet-template.csv` ใน Google Sheets (ไฟล์ › นำเข้า › อัปโหลด) หรือสร้างชีตใหม่โดยใช้หัวคอลัมน์ 17 ช่องตามตัวอย่าง
2. หนึ่งแถว = หนึ่งจังหวะ แผนเดียวกันใช้ `id` เดียวกัน เรียง `step` จาก 0 ขึ้นไป
   - `ball` = ผู้เล่นที่ถือบอล (1–5)
   - `x1,z1 … x5,z5` = ตำแหน่งผู้เล่น หน่วยเมตร (x: 0–14 จากเส้นหลังแป้น, z: -7.5 ถึง 7.5, ห่วงอยู่ที่ x=1.6, z=0)
   - ห้ามใส่เครื่องหมายลูกน้ำในช่อง `note`
3. ไฟล์ › แชร์ › **เผยแพร่ไปยังเว็บ** › เลือกชีต › รูปแบบ **CSV** › เผยแพร่ แล้วคัดลอกลิงก์
4. เปิด `config.js` วางลิงก์ลงใน `PLAYS_CSV: "..."` แล้วอัปโหลดไฟล์ใหม่
5. เปิดเว็บ แผนในชีตจะโหลดอัตโนมัติ (แก้ชีตแล้วรีเฟรชหน้า เห็นผลภายในไม่กี่นาที) ถ้าดึงไม่ได้ แอปใช้แผนในตัวแทนและแจ้งเตือนในแผงขวา

## 4) ติดตั้งเป็นแอป
- Android/Chrome: เมนู ⋮ › ติดตั้งแอป
- iPhone/Safari: ปุ่มแชร์ › เพิ่มไปยังหน้าจอโฮม
- คอมพิวเตอร์ Chrome/Edge: ไอคอนติดตั้งที่แถบที่อยู่

## 5) แก้ปัญหา
- หน้าจอดำ: กด F12 ดูข้อความสีแดงใน Console
- แก้ไฟล์แล้วหน้าเว็บไม่เปลี่ยน: กด Ctrl+Shift+R (ล้างแคช) หรือเปลี่ยนค่า `V` ใน sw.js เป็น hoops-v2
- ภาพกระตุกบนมือถือ: ปิดแท็บอื่น หรือใช้ระดับป้องกัน "ทั่วไป"
